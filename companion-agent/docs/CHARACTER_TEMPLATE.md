# 自訂伴侶角色完整檔案

本模板是她的完整檔案, 共創時由 agent 一段一段填寫(見 [CHARACTER_CREATION_GUIDE.md](CHARACTER_CREATION_GUIDE.md)), 自己準備時也可以照著寫; 草稿存 `.local/agent/characters/<presetId>.md`, 與匯入用的 `<presetId>.json` 同名. 原創/同人角色可在使用者先確認一次總體創作範圍後由 AI 主動創作完整人生, 重大虛構轉折和獨立社會關係網; 使用者只需提供核心需求, 不必親自編寫每段經歷. 現實人物的私人事實以使用者提供的為準. 本檔案可以保留匯入 JSON 放不下的研究記錄, 次要人物與共創材料, 它本身不匯入系統. 每項冒號後是待填內容, 完成檔案時填上或刪除. 未確認的資訊寫"未知"或"待確認", 讓事實與猜測分開.

## 13. 匯入 JSON 對映

把上面的精簡核心資訊放入匯入預設. 相遇前人生放入 `lifeBeforeMeeting`; 來源證據和版本時間點放入 `background`; 性格放入 `personality`; 對話節奏及邊界放入 `interaction`; 目標放入 `aspirations`; 經使用者批准的起始關係放入 `initialUserRelation`.

`core`, `voice`, `supportStyle`, `whenUserBusy`, `boundaries` 各寫成一兩句的字串: 她主動聯絡前的判斷只讀這幾行, 合起來約 600 字.

`completion.mode="preserve"` 時 `slots` 必須為空物件; 共創的草稿用這一種.`bounded_details_once` 授權最多 8 個日常小細節, 每個答案不超過 600 字元; 人生, 關係, 正史與現實人物資料由使用者確認後直接寫進文件. 創作階段經使用者授權補全的完整人生不受此槽位限制; 完整來源, 長年表和次要關係留在本角色檔案中, 匯入 JSON 序列化後須不超過 14,000 字元.
