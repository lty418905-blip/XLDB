# XLDB

本地记忆—情绪管理插件，支持 SillyTavern / Tavern Helper 多 NPC 跑团与独立 Agent 伴侣模式。

**当前是可安装 MVP 扩展版，不是完整产品完成版。**本次公开版本的运行代码来自已验证的 `bd32a80d2ffa` 安装候选，未加入尚在规划中的量化检索或语义再激活。

## 下载与安装

点击 GitHub 的 **Code → Download ZIP**，解压后进入包含 `START-XLDB.cmd` 的目录。

- **酒馆：**运行 `START-XLDB.cmd`，在打开的酒馆中，通过 Tavern Helper 导入根目录 `XLDB-酒馆.json` 并启用。也可新建脚本粘贴 `XLDB-酒馆.js`，两者选一。首次配对后自动连接本机核心；各模型环节的 API 信息由用户填写。
- **Agent：**把压缩包交给有本地命令执行能力的 Agent，要求按 [INSTALL_AGENT.md](INSTALL_AGENT.md) 安装。后台推理要求宿主支持独立子代理；不需要启动酒馆。

支持 Windows x64。安装器使用 Node.js 24.18.1 或兼容的24.x版本；缺失时下载固定便携版本。依赖、缓存及运行数据放在安装目录 `.local/`，认证资料按启动器规则放入相邻私有目录；不安装 Python 或全局 npm 包。首次安装需要网络；已有缓存可离线恢复。

## 当前能力

- 事实与情景记忆、角色知情范围、来源修订、选择性文本模糊与逐字线索再激活。
- OpenHer 神经情绪、长期方向性关系及可纠正偏好/画像。
- 跑团／伴侣双模式、时钟、承诺、账本、物品和受控主动联系。
- 固定工作台与折叠变量面板，可选虚拟生理状态。
- 跑团地图：JSON 预览导入导出、背景整理候选、随正文更新、层级及拖动布局。
- 六份伴侣初始预设、自定义导入、保存点、分支、撤销与备份恢复。
