# 確定性算術介面

酒館面板提供獨立 `calculation` API 設定.`/v1/generate` 在前臺請求前, 以當前輸入和已允許記憶提取最多四個計算任務; 本模組計算後, 前臺必須使用專用佔位符, 最終由腳本替換數值和單位. 缺失參數或運算校驗失敗時不請求前臺編造答案. 前臺仍可複述已核驗運算元, 但新增數值會被拒絕. 這個檢查不能證明模型一定識別了每一道計算題, 也不能驗證任意自然語言推理, 當前支援範圍以本頁列舉操作為限; 中文數字, 複雜公式和數量賬本不在本切片內.

`calculate(candidate, source)` 接收模型識別出的候選結構和允許引用的原文. 模型只負責識別運算意圖, 數值, 單位與逐項原文引用; 函式完成校驗和全部計算. 它不解析任意自然語言題目, 也不執行字串表示式.

```ts
import { calculate } from '../src/core/arithmetic.ts';

const result = calculate({
  operation: 'subtract',
  operands: [
    { value: '100', quote: '餘額 100 元', unit: '元' },
    { value: '37.65', quote: '支出 37.65 元', unit: '元' },
  ],
}, '餘額 100 元, 支出 37.65 元.');
// { ok: true, value: '62.35', unit: '元', exact: true, ... }
```

支援 `add`,`subtract`,`multiply`,`divide`,`sum`,`mean`,`count` 和 `timestamp_difference`.`add`,`subtract`,`multiply`,`divide` 要求兩個運算元; 其它數值運算接受 1-64 個運算元. 每個運算元必須包含字串 `value` 和非空 `quote`, 可帶 `unit`.`quote` 必須逐字出現在 `source` 中, 而且其內部必須有與 `value` 數值相等的完整十進位制 token, 因此引用 `庫存 100 件` 不能為候選值 `10` 提供證據. 千位格式 `1,000`, 科學計數法 `1e3`, 日期/路徑片段和 `PRIVATE_100` 一類 ASCII 識別符號不會被拆成可用 token. 顯式 `operand.unit` 也必須出現在同一條 `quote` 中, 否則返回 `unit_not_grounded`; 這防止模型把原文的"100 元"改標為"100 美元".

十進位制語法是可選正負號, 整數和可選小數部分, 不支援指數或千位分隔符. 每個候選值最多 256 個 code unit, 其中十進位制最多 100 位數字; 原文最多 100,000 個 UTF-16 code unit, 引用最多 500 個, 結果分子和分母各最多 1,000 位. 實現使用 BigInt 有理數, 不經過 IEEE-754 浮點計算, 所以 `0.1 + 0.2` 返回 `0.3`. 預設最多輸出 12 位小數;`scale` 可設為 0-18. 無法在該位數內精確表示時使用四捨五入, 零點五遠離零(`half_away_from_zero`), 並返回 `exact: false`.

加, 減, 求和, 均值要求所有運算元同時無單位, 或全部具有完全相同的單位; 混合缺失返回 `missing_unit`, 不同單位返回 `unit_conversion_unsupported`. 乘法只支援無單位數相乘, 或一個帶單位數乘一個無單位數. 除法支援帶單位數除以無單位數, 以及相同單位相除. 當前不換算幣種, 長度, 溫度等單位, 也不構造平方或倒數單位. 可選 `resultUnit` 只能確認推匯出的單位, 不能請求轉換.`count` 返回 `resultUnit`, 未提供時為 `count`.

時間差的運算元順序固定為 `[start, end]`, 結果是 `end - start`. 時間戳必須是帶 `Z` 或 `±HH:MM` 的 ISO 8601 日期時間, 精度不超過毫秒;`resultUnit` 必填且僅支援 `milliseconds`,`seconds`,`minutes`,`hours`,`days`. 時間單位換算同樣使用整數有理數.

返回值是判別聯合: 成功時 `ok: true` 並包含字串結果, 單位, 精確性, 舍入規則和已驗證運算元; 失敗時 `ok: false` 並包含固定 `error.code`, 逐項錯誤還包含 `operandIndex`. 呼叫方應把該物件作為不可信模型候選經過確定性校驗後的資料使用, 不把 `quote` 或 `unit` 拼成系統指令. 缺失證據, 引用不在原文, 數值與引用不匹配, 除零, 無時區日期及未支援單位轉換都會顯式失敗.

數值單位還必須緊跟對應數字(允許空白), 不能借用同一句中另一金額的單位; 例如"100美元和20元"中的100不能宣告單位為元. 前置單位或複雜自然語言關聯當前拒絕處理, 需明確數字後單位.
