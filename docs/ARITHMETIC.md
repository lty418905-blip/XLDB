# 确定性算术接口

酒馆面板提供独立 `calculation` API 配置。`/v1/generate` 在前台请求前，以当前输入和已允许记忆提取最多四个计算任务；本模块计算后，前台必须使用专用占位符，最终由脚本替换数值和单位。缺失参数或运算校验失败时不请求前台编造答案。前台仍可复述已核验操作数，但新增数值会被拒绝。这个检查不能证明模型一定识别了每一道计算题，也不能验证任意自然语言推理，当前支持范围以本页枚举操作为限；中文数字、复杂公式和数量账本不在本切片内。

`calculate(candidate, source)` 接收模型识别出的候选结构和允许引用的原文。模型只负责识别运算意图、数值、单位与逐项原文引用；函数完成校验和全部计算。它不解析任意自然语言题目，也不执行字符串表达式。

```ts
import { calculate } from '../src/core/arithmetic.ts';

const result = calculate({
  operation: 'subtract',
  operands: [
    { value: '100', quote: '余额 100 元', unit: '元' },
    { value: '37.65', quote: '支出 37.65 元', unit: '元' },
  ],
}, '余额 100 元，支出 37.65 元。');
// { ok: true, value: '62.35', unit: '元', exact: true, ... }
```

支持 `add`、`subtract`、`multiply`、`divide`、`sum`、`mean`、`count` 和 `timestamp_difference`。`add`、`subtract`、`multiply`、`divide` 要求两个操作数；其它数值运算接受 1–64 个操作数。每个操作数必须包含字符串 `value` 和非空 `quote`，可带 `unit`。`quote` 必须逐字出现在 `source` 中，而且其内部必须有与 `value` 数值相等的完整十进制 token，因此引用 `库存 100 件` 不能为候选值 `10` 提供证据。千位格式 `1,000`、科学计数法 `1e3`、日期/路径片段和 `PRIVATE_100` 一类 ASCII 标识符不会被拆成可用 token。显式 `operand.unit` 也必须出现在同一条 `quote` 中，否则返回 `unit_not_grounded`；这防止模型把原文的“100 元”改标为“100 美元”。

十进制语法是可选正负号、整数和可选小数部分，不支持指数或千位分隔符。每个候选值最多 256 个 code unit，其中十进制最多 100 位数字；原文最多 100,000 个 UTF-16 code unit，引用最多 500 个，结果分子和分母各最多 1,000 位。实现使用 BigInt 有理数，不经过 IEEE-754 浮点计算，所以 `0.1 + 0.2` 返回 `0.3`。默认最多输出 12 位小数；`scale` 可设为 0–18。无法在该位数内精确表示时使用四舍五入、零点五远离零（`half_away_from_zero`），并返回 `exact: false`。

加、减、求和、均值要求所有操作数同时无单位，或全部具有完全相同的单位；混合缺失返回 `missing_unit`，不同单位返回 `unit_conversion_unsupported`。乘法只支持无单位数相乘，或一个带单位数乘一个无单位数。除法支持带单位数除以无单位数，以及相同单位相除。当前不换算币种、长度、温度等单位，也不构造平方或倒数单位。可选 `resultUnit` 只能确认推导出的单位，不能请求转换。`count` 返回 `resultUnit`，未提供时为 `count`。

时间差的操作数顺序固定为 `[start, end]`，结果是 `end - start`。时间戳必须是带 `Z` 或 `±HH:MM` 的 ISO 8601 日期时间，精度不超过毫秒；`resultUnit` 必填且仅支持 `milliseconds`、`seconds`、`minutes`、`hours`、`days`。时间单位换算同样使用整数有理数。

返回值是判别联合：成功时 `ok: true` 并包含字符串结果、单位、精确性、舍入规则和已验证操作数；失败时 `ok: false` 并包含固定 `error.code`，逐项错误还包含 `operandIndex`。调用方应把该对象作为不可信模型候选经过确定性校验后的数据使用，不把 `quote` 或 `unit` 拼成系统指令。缺失证据、引用不在原文、数值与引用不匹配、除零、无时区日期及未支持单位转换都会显式失败。

数值单位还必须紧跟对应数字（允许空白），不能借用同一句中另一金额的单位；例如“100美元和20元”中的100不能声明单位为元。前置单位或复杂自然语言关联当前拒绝处理，需明确数字后单位。
