# 自定义伴侣角色完整档案

本模板用于访谈后整理完整资料。原创／同人角色可在用户先确认一次总体创作范围后由 AI 主动创作完整人生、重大虚构转折和独立社会关系网；用户只需提供核心需求，不必亲自编写每段经历。此授权用于创作阶段，不用于编造现实人物私人事实。它可以保留导入 JSON 放不下的研究记录和次要人物，不直接导入系统。方括号内容是填写提示，完成档案时替换或删除。未确认的信息写“未知”或“待确认”，不要用猜测填满。

## 12. 导入 JSON 映射

把上面的精简核心信息放入导入预设。相遇前人生放入 `lifeBeforeMeeting`；来源证据和版本时间点放入 `background`；性格放入 `personality`；对话节奏及边界放入 `interaction`；目标放入 `aspirations`；经用户批准的起始关系放入 `initialUserRelation`。

`completion.mode="preserve"` 时 `slots` 必须为空对象。`bounded_details_once` 仅授权最多 8 个低风险小细节，且每个答案不超过 600 字符；不要借此补造人生、关系、正史或现实人物私人资料。创作阶段经用户授权补全的完整人生不受此槽位限制；完整来源、长年表和次要关系留在本角色档案中，导入 JSON 序列化后须不超过 14,000 字符。
