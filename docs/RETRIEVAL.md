# 记忆检索

当前处于 MVP 测试阶段，功能可能存在实际应用问题。

## 配置

在工作区 `.local/agent/retrieval-api.txt` 填写两个独立服务：

```json
{
  "embedding": {"baseUrl":"https://你的服务/v1", "key":"你的密钥", "model":"服务提供的嵌入模型名"},
  "reranker": {"baseUrl":"https://你的服务/v1", "key":"你的密钥", "model":"服务提供的重排模型名"}
}
```

支持兼容 embeddings 和 rerank 协议的接口，地址可为 API 根路径或完整端点。本机免认证服务可把 key 留空。密钥只保存在本地文件，Agent 不应把它发给子代理或粘贴到聊天。

未配置时使用本地 BM25 关键词检索；配置 embedding 后加入语义向量检索，配置 reranker 后对候选重新排序。两者可分别配置。检索服务接收当前查询与允许访问的记忆文本。

## 遗忘与再激活

事实、情景、主观感觉和事件锚点分开处理。重要事实与承诺受到保留规则保护；允许模糊的外围细节按保留层级改变前台文本，并同步调整检索向量的精度。原始已接受事件不因这种模糊而改写。

未配置 embedding 时，原文中的独特逐字线索可帮助再激活；配置后还可使用具有区分度的语义线索。再激活遵守来源、角色知识和访问范围，不能恢复已删除或无权查看的内容。

用户可纠正来源、调整访问粒度或删除记录。索引是可重建的派生数据，角色输入始终以当前有效权限与保留层级为准。
