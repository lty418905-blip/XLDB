# 中文双类记忆检索

`src/memory/retrieval.ts` 是可重建的 LanceDB 投影，SQLite 仍是唯一权威。每次查询先按世界、会话、分支、角色、获知时间、来源状态与遗忘层级筛选；异步结果返回后再次检查权威版本。最多返回 20 条。

## 记忆语义

新记忆区分 `fact` 和 `episode`。事实保存有来源的原话、约定与事件，不携带主观 feeling；获知来源仍区分 observed/heard/private/thought/inferred，记录原话不等于证实外界事实。情景保存角色当时的场景、参与者、感官线索、评价、感受以及 `explicit/inferred` 依据。情景的来源引用必须来自同一已接受消息中该角色可见的片段，可连接公开事件和该角色自己的私密想法，不能连接他人的私密内容。

模糊情景只输出准许的大意、感觉、锚点及依据类型，不输出完整 episode 对象；hidden 不输出情景细节。事实和情景共同竞争相关性，受保护事实表示保留而不是每次强行注入。非空查询不以无关近期内容填满结果；空查询作为最近记忆查看。旧记录标为 legacy，保留原有访问规则，不自动重分类。

情景与 Critic 接收该角色在对应事件之前的情感状态，按来源顺序处理；纠正、删除早期经历或修改角色设定后，受影响的后续分析失效并重算。访问设置在同一权威表中绑定来源、角色、类型与原始 detail 的内容哈希，不绑定候选顺序。模型暂时不提取某条记忆、角色暂时失去该经历或来源升修订，都不会删除原限制；旧版按序号保存的控制在重算时迁移。若模型改写候选导致受限旧项无法匹配，新未匹配项保守采用该来源该角色最严格的旧限制；可能多隐藏内容，用户可在管理界面重新调整，明确设置 clear 优先于旧限制。这是控制迁移的限制，不是自然遗忘策略。

## 分词与排序

默认 ICU 产生中文词项，再以 whitespace FTS 建索引，索引与查询使用相同正规化。只移除查询助词并扩展约定/承诺/答应三个通用近义词。混合模式取 BM25 和向量各前 40 项做 RRF，事实或情景意图仅提供轻微排序偏好，每项最多 20 项进入重排。明确用顿号、分号等列出的多项问题分别检索，批量生成查询向量，并按各项排名轮流合并，总结果仍最多 20 项；不按固定业务词表拆题。

重排默认只排序，不把未经当前场景校准的分数当概率。此前 bge-reranker-v2-m3 的 0.15 门槛在长对话冻结对照中排除了仍相关的低分事实，现已取消默认门槛；直接 Retrieval 使用者仍可显式设置 `minimumRerankScore`。取消门槛可能增加近似但不能回答问题的候选，前台必须依据实际来源作答、允许未知；下面2026-09-19的旧测量不是本版本无答案质量证明。

已核验 LanceDB 0.39.0 的 jieba/default 本地词典路径。直接原生 jieba FTS 在“为什么再次见到他会紧张？”上出现 token position 下溢和巨大内存分配崩溃，证据保留于 `.local/logs/tokenizers`。安全适配只取 token 文本，由 whitespace 重建位置，避免该故障；但当前 native tokenize 每次重新加载词典，延迟显著高于 ICU，因此产品默认 ICU。jieba 是可选开发比较项，词典未放进默认安装包，无 Python 产品依赖。资料：[Lance tokenizer](https://lance.org/guide/tokenizer/)。

## 配置与缓存

`embedding` 与 `reranker` 独立配置 `{baseUrl,key,model}`，全部为空即关闭。默认无供应商。API 根路径或完整 embeddings/rerank 路径均可；密钥仅经 Bearer 请求头发送，禁止重定向。一次查询的全部外部请求共享默认 15 秒预算，SDK 可用 `RetrievalOptions.externalTimeoutMs` 调整；这不是整轮首字时间保证。长对话冻结样本的成功冷检索约7–10秒，原3秒预算无法覆盖该链路，因此调整预算。

嵌入网络、HTTP 或超时失败时，从同一当前授权快照建立本地 BM25 投影，返回 `bm25-fallback`。仅重排失败时保留已经取得的合法混合候选，返回 `hybrid-fallback`（没有向量配置时仍为 `bm25-fallback`）。结果带 `fallbackReason`，酒馆展示降级状态；下一次查询重新尝试服务，不缓存重排故障作为正常结果。非法响应、配置和本地索引错误仍明确失败。正常模式为 bm25、bm25+rerank、hybrid、hybrid+rerank；降级不能声称与带重排的检索具有相同质量。

投影指纹包含已允许文本、类型、分词器与嵌入端点/模型；不因无关权威版本变化全量重建。文本不变复用磁盘向量，新增或更改行按最多 32 条批量嵌入，删除不重新嵌入其它行。重启复用当前投影。结果缓存每作用域 64 项、驻留表最多 16 个作用域，查询向量缓存最多 64 项；访问或来源变化使结果失效。配置密钥变化使请求缓存失效，但凭据不落入投影元数据。各作用域独立串行，不让所有角色共用全局队列。

## 2026-09-19 固定场景测量

107 条合成记忆，41 问（34 可回答、7 无答案）；73 事实、34 情景。旧算法快照与新算法使用相同 v2 fixture 与真实供应商。质量门槛在优化版真实结果产生前写入 `docs/retrieval-acceptance.md`。

| 链路 | Recall@5 | 无答案仍返回内容 | 不同查询 p95 | 冷建库+首查询 |
| --- | --- | --- | --- | --- |
| 旧 hybrid+BGE重排 | 17.6% | 7/7 | 3378 ms | 1427 ms |
| 新 ICU hybrid+BGE重排 | 100% | 1/7 | 3522 ms | 1947 ms |
| 新 ICU BM25+BGE重排 | 100% | 1/7 | 328 ms | 367 ms |

最后一条链路事实与情景组 Recall@5 都为 100%、无越权命中；重复查询 p95 约 0.52 ms。全混合模式质量通过但不同查询延迟未通过本轮门槛，保持显式可选。离线中文 BM25：ICU Recall@5=100%，jieba=97.1%；不同查询 p95 分别约 3.07 ms 与 143 ms。纯 BM25 的 2/7 无答案误召回未过门槛，不能把无外部模型模式称作同等质量。

原始报告在 `.local/benchmarks/retrieval/`：`2026-09-19T17-23-29-121Z-baseline.json`、`2026-09-19T17-27-08-002Z-optimized.json`、`2026-09-19T17-28-38-039Z-optimized.json`。每份记录环境、源码与夹具哈希、逐题 ID 和延迟；旧失败及 v1 fixture 保留。重复查询和不同查询分开统计，不能拿缓存延迟冒充首次查询延迟。网络测量是单轮样本，不是稳定延迟保证。

这组问题多含名字或场景词，不证明任意别称/隐喻/长对话泛化，也未覆盖百万条规模。最后剩余的无答案误召回是情景类相似回忆，前台仍需区分联想与回答依据。测试与真实模型提取分别验收，不把手工 fixture 当作自动形成质量。


## 选择性保留、自然模糊与再激活

新记忆提取可标注 retention，并附原文依据。重要经历、强情绪核心、目标、承诺、关系锚点与身份/同意/金额等应保留；没有标注的旧记录也保留。没有每轮遗忘配额。仅明确的外围细节随时间模糊：情景30天、事实60天后只提供概要，180天后提供感觉和事件锚点，受保护事实仍保留。上述期限是当前保守工程默认值，尚无长期试用校准。

伴侣使用现实时间，跑团使用剧情时间。检索索引和前台在模糊后的同一投影上工作，精确详情不会先交给前台再要求它装作忘记；需改写时由前置模型生成标明遗忘的材料。手动访问限制优先，手动指定清楚也优先。原始已接受记录不因自然模糊而被改写。

当前输入命中同一记忆原文内的独特线索，可在已有访问范围内再激活；后来已接受的可见正文再次出现线索，可刷新该记忆的保留时间。删除这段复习来源后会撤销刷新效果。删除、版本失效、越权和手动隐藏均不会被再激活绕过。当前只支持有来源的逐字线索，不声称覆盖所有语义相似场景。
